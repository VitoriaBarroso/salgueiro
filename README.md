# Salgueiro — Aplicativo Mobile de Literatura 

> Projeto acadêmico desenvolvido para a disciplina de **Programação para Dispositivos Móveis I**.

---

## 
* **Nome da Aplicação:** Salgueiro
* **Tecnologia / Framework:** React Native (Expo SDK 58) com React Navigation Stack

---

##  Descrição Resumida
O **Salgueiro** é um aplicativo mobile conceitual focado na experiência de leitura aconchegante, inspirado na estética poética dos álbuns *Red* e *Folklore* da Taylor Swift (tons vinho, creme e verde musgo). O projeto conta com autenticação simulada, navegação entre telas via Toolbar e layout institucional/literário.
